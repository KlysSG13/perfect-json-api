# Тарификация и экономика

## Как считаются кредиты
Кредиты — целые числа, округление вверх (`math.ceil`).

```
стоимость запроса =
    CREDIT_BASE_COST × число_вызовов_LLM
  + CREDIT_COST_PER_1K_INPUT_CHARS × (символы_входа/1000) × число_вызовов
  + CREDIT_COST_PER_1K_OUTPUT_TOKENS × (выходные_токены_суммарно/1000)
```

- Оценка до вызова: база + вход + запас ~1000 выходных токенов.
- Максимум (холд): (repairs+1) вызовов, вход на каждый, максимум
  `LLM_MAX_OUTPUT_TOKENS` выходных токенов на вызов; ограничен
  `MAX_COST_DEFAULT_CREDITS`, пер-ключевым `per_request_max_cost_credits`
  и `options.max_cost_credits`.
- Провайдер не вернул usage → выходные токены оцениваются как
  `длина_ответа/4`.
- Дефолтные цены: короткий запрос ≈ 2–4 кредита; с одной автопочинкой ≈ ×2.

## Правила списаний
| Ситуация | Списание |
|---|---|
| Ошибки клиента (пусто/схема/лимит размера) | нет |
| Недостаточно баланса (до LLM) | нет |
| Недоступен LLM (после ретрая и fallback) | нет, холд освобождается |
| Успех | фактическая стоимость |
| Провал валидации после всех попыток | фактическая (работа выполнена) |
| Автопочинки остановлены лимитом стоимости | фактическая за выполненные вызовы |

Аномальный usage провайдера (фактическая стоимость > холда): списывается
не больше холда, в `usage_logs.meta` ставится `usage_over_hold`, админам
уходит событие `usage_over_hold`.

## Пакеты кредитов (PAYMENTS_ENABLED)
| Код | Кредиты | Цена |
|---|---|---|
| starter | 1 000 | $9 |
| growth | 5 000 | $39 |
| scale | 25 000 | $149 |

Свои пакеты: таблица `credit_packages` (код, кредиты, цена, валюта).
Пополнение — только Telegram Stars через бота (`/buy`, инвойс XTR):
единственный пользовательский метод с 3.0 (Stripe/Fake-checkout отключены,
410). Возвраты и сверка — CLI (`refund-payment`, `reconcile-payment`).

## Автопополнение
Не реализовано в 2.0 (ROADMAP). Текущая альтернатива: события
`balance.low` (`BALANCE_LOW_THRESHOLD`) → вебхук клиента/алерт оператору →
ручное/скриптовое пополнение `POST /admin/api-keys/{id}/credits`.

## Возвраты
- Вебхук `charge.refunded` → статус `refunded`, кредиты снимаются
  (`refund`-транзакция), баланс clamped ≥ 0.
- Политика оператора: возврат неиспользованных кредитов в течение N дней
  (рекомендация N=14); израсходованные не возвращаются.

## Налоги
Ответственность оператора: самозанятость/юрлицо определяет чеки и ставки
(для НПД РФ: 4% физлица / 6% юрлица, лимит 2,4 млн ₽/год — поправьте под
свою юрисдикцию). Сервис чеки не формирует — интегрируйте через платёжного
провайдера.

## Примеры расчёта (цены по умолчанию)
- Счёт 2 000 символов, 1 вызов, 300 выходных токенов:
  `1 + 2 000/1000×0.5 + 300/1000×2 = 1+1+0.6 → 3 кредита` (холд 4).
- Резюме 8 000 символов, 1 автопочинка (2 вызова), 800+900 токенов:
  `2×1 + 2×4 + 1.7×2 ≈ 13.4 → 14 кредитов` (холд по капу 50).
- Экономика запроса: см. `GET /admin/economics`
  (`PROVIDER_COST_PER_1K_*`, `CREDIT_PRICE_USD`, флаг `estimated`).
