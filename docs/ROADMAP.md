# Roadmap

## 2.1 (ближайший релиз)
- **Self-serve**: организации/пользователи/сессии уже в БД; Jinja2-кабинет
  `/web`, CSRF, роли, скоупы (детали: docs/SELF_SERVE.md).
- **Telegram Stars**: провайдер `telegram_stars` поверх готового
  платёжного контура (send_invoice XTR → successful_payment →
  handle_provider_event).
- **Автопополнение**: webhook `balance.low` → автоматический checkout
  пакета (по согласию клиента).
- Авто-экспирация «зависших» холдов (статус `expired` + release-транзакция
  по расписанию).

## 2.2
- Вынос воркера задач в отдельный сервис (масштабирование consumers);
  Redis-очередь с конкурентными воркерами.
- Конструктор схем: пользователь выбирает поля → сервис генерирует JSON
  Schema → тест на примере (`/v1/schema-builder`).
- Библиотека отраслевых пресетов: счета/акты/договоры/лиды/вакансии/
  заказы/чаты поддержки/сметы.
- Мультимодельность: маршрутизация по сложности задачи, лимиты на дорогую
  модель, выбор модели на уровне ключа, аналитика по провайдерам.

## 2.3+
- Маркетплейс шаблонов: публикация пресетов, версии, рейтинги, платные и
  бесплатные шаблоны.
- Интеграции: Postman collection, н8n node, Make module, Python SDK,
  TypeScript SDK.
- Корпоративные функции: SSO (OIDC/SAML), расширенный аудит, экспорт
  логов, ограничения по IP, BYO LLM key, on-premises.
- Multi-region и SLA.
