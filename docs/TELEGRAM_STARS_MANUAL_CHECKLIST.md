# Ручной чеклист Telegram Stars (перед запуском)

Требуется: тестовый бот с включёнными Stars (BotFather → Payments),
`TELEGRAM_BOT_TOKEN`, `.env` с `PAYMENTS_ENABLED=true`,
`TELEGRAM_STARS_ENABLED=true`, применённые миграции, `seed-packages`.

## Что проверить вне бота
- API-ключ клиента работает в REST: `POST /v1/transform` с `X-API-Key` —
  списания идут с личного баланса;
- `GET /v1/payments` этим ключом показывает его платежи;
- `POST /v1/payments/checkout` → 410 `payment_provider_disabled`.

## Если платёж прошёл, а кредиты не пришли
1. `payments-list --status received` → найти charge_id.
2. Причина в логах (`payment.credit_failed` / `payment.package_problem`).
3. Пакет неактивен → активировать и `reconcile-payment`.
4. Иначе после почины причины — `reconcile-payment`; если зачислить
   невозможно — вернуть Stars пользователю и `refund-payment`/закрыть
   вручную с пометкой problem.
