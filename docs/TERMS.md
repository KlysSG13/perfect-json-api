# Условия использования (шаблон оператора)

> Это заготовка, а не юридическая консультация. Перед запуском коммерческой
> эксплуатации адаптируйте под свою юрисдикцию и условия процессинга.

## 1. Предмет
Оператор предоставляет API-сервис преобразования неструктурированных данных
в валидный JSON по JSON Schema (далее — «Сервис»). Использование = принятие
условий.

## 2. Аккаунт и ключи
- Доступ — по API-ключам. Клиент отвечает за сохранность ключей; ключ
  скомпрометирован — немедленно отзовите (403 через `is_active=false`).
- Кредиты списываются за фактически выполненную работу (см.
  docs/PRICING.md). При недоступности провайдера списания не происходит.

## 3. Приемлемое использование
См. docs/ACCEPTABLE_USE.md. Запрещённый контент → блокировка ключа без
возврата кредитов за уже обработанные запросы.

## 4. Уровень сервиса
MVP-уровень: без SLA; целевая доступность — по мониторингу оператора
(см. docs/OPERATIONS.md). Планы SLA — docs/ROADMAP.md.

## 5. Данные
Обрабатываются согласно docs/PRIVACY.md. Клиент гарантирует права на
передачу данных в Сервис.

## 6. Оплата и возвраты
Пакеты кредитов оплачиваются вперёд. Возвраты — по политике
docs/PRICING.md (возврат неиспользованных кредитов в пределах срока
хранения данных о платеже). Налоги — ответственность оператора
(самозанятость/юрлицо оператора определяют чеки и ставки).

## 7. Ответственность
Сервис предоставляется «как есть». Ответственность оператора ограничена
суммой платежей клиента за последние 30 дней.

## 8. Изменения
Условия и цены могут меняться с уведомлением за 14 дней (e-mail/вебхук
`payment.*`/канал оператора).
