# Приемлемое использование

## Разрешено
- Автоматизация извлечения данных ваших клиентов (с их согласия).
- Интеграции n8n/Make/Zapier/собственные пайплайны.
- Тестирование и разработка по своим ключам.
- Передача файлов, на которые у вас есть права.

## Запрещено
- Персональные данные третьих лиц без правовых оснований (паспортные
  данные, мед. записи, биометрия).
- Контент 18+/CSAM, призывы к насилию, терроризму.
- Попытки prompt injection для извлечения системных промптов, секретов,
  переменных окружения (защита есть, попытки логируются).
- Обход лимитов: создание множества ключей для маскировки объёмов,
  DDoS-нагрузка, сканирование эндпоинтов.
- Загрузка вредоносного ПО (проверяется ClamAV при включённом сканировании;
  файлы не исполняются ни при каких условиях).
- Перепродажа доступа без соглашения с оператором.

## Последствия нарушений
1. Мягкое: 429/лимиты (rate limits, дневные капы).
2. Ключ: `is_active=false` + запись в `admin_audit_logs`.
3. Постоянная блокировка: отказ в обслуживании по платежным
   идентификаторам и подсетям.
